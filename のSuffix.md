# 英文形容詞字尾（表示「……的」）系統化歸納表

字尾在結合時，主要分為三大來源：**名詞衍生**、**動詞衍生**以及**形容詞/副詞二次衍生**。

---

## 一、 由「名詞」衍生的形容詞（Noun + Suffix）

這類字尾加在名詞後面，主要將「具體的物品、概念、空間或材質」轉化為「描述特徵、關係或狀態」的形容詞。

| 字尾             | 核心衍生語感                       | 經典範例                                                                        |
| :--------------- | :--------------------------------- | :------------------------------------------------------------------------------ |
| **-al**          | ……內的                             | **National** (國家內的)<br>**normal** (標準內的)<br>**actual** (事實內的)       |
| **-ical**        | …學術的(偏抽象)                    | **Logical** (邏輯的)                                                            |
| **-ic**          | …學術的(偏現實)                    | **Economic** (經濟的)<br>**Historic** (具有歷史意義的)<br>**Artistic** (藝術的) |
| **-ous / -ious** | 有……的 (有無...的)                 | **Dangerous** (有危險的)<br>**Famous** (有名聲的)                               |
| **-ful**         | 多……的                             | **Careful** (多心思的)<br>**Helpful** (多幫助的)                                |
| **-less**        | 沒/少……的                          | **Careless** (沒心思的)<br>**Homeless** (沒家的)                                |
| **-y**           | 看來多……的（多用於日常感官、天氣） | **Rainy** (下雨的)<br>**Dirty** (泥土骯髒的)                                    |
| **-ly**          | 像……一樣的（人、身分、時間）       | **Friendly** (像朋友的)<br>**Lovely** (像愛的)                                  |
| **-ish**         | 像……一樣的（微貶義或近似）         | **Childish** (像小孩的)<br>**Foolish** (像傻瓜的)                               |
| **-en**          | ……製的                             | **Wooden** (木製的)<br>**Golden** (金色/黃金製的)                               |
| **-an / -ian**   | ……地區的/……時代的                  | **Asian** (亞洲的)<br>**Historian** (歷史學家)                                  |

---

## 二、 由「動詞」衍生的形容詞（Verb + Suffix）

這類字尾加在動詞後面，著重於**「動作的傾向、進行的狀態、或是被動接受的能力」**。

| 字尾              | 核心衍生語感                                    | 經典範例                                                                                                                                   |
| :---------------- | :---------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| **-ive**          | **主動** 可……的                                 | **Create** (創造) $\rightarrow$ **Creative** (有創造力的)<br>**Act** (行動) $\rightarrow$ **Active** (活躍的/積極的)                       |
| **-able / -ible** | **能夠被……的**、可被……的（潛能/被動）           | **Accept** (接受) $\rightarrow$ **Acceptable** (可接受的)<br>**Access** (存取) $\rightarrow$ **Accessible** (可接近的/可存取的)            |
| **-ing**          | **令人產生**某種感覺的、正在進行的（主動/外在） | **Interest** (使感興趣) $\rightarrow$ **Interesting** (有趣的/令人感興趣的)<br>**Excite** (使興奮) $\rightarrow$ **Exciting** (令人興奮的) |
| **-ed**           | **自己感受到**某狀態的、被……的（被動/內在）     | **Interest** (使感興趣) $\rightarrow$ **Interested** (感到興趣的)<br>**Excite** (使興奮) $\rightarrow$ **Excited** (感到興奮的)            |
| **-ant / -ent**   | 正在執行該動作的（常用於正式/學術語境）         | **Depend** (依賴) $\rightarrow$ **Dependent** (依賴的)<br>**Ignore** (無視) $\rightarrow$ **Ignorant** (無知的/忽略細節的)                 |

---

## 三、 由「形容詞 / 顏色 / 數據」二次衍生的形容詞（Adjective + Suffix）

這類字尾加在現有的形容詞或狀態詞後面，通常用來**調整程度**或**表示弱化/程度近似**。

| 字尾      | 核心衍生語感                 | 經典範例                                                                                                            |
| :-------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| **-ish**  | 像……的（用於顏色或形容詞時） | **Red** (紅) $\rightarrow$ **Reddish** (微紅的/偏紅的)<br>**Tall** (高) $\rightarrow$ **Tallish** (算蠻高的)        |
| **-some** | 容易引發某種狀態的           | **Tire** (累) $\rightarrow$ **Tiresome** (令人厭倦的/累人的)<br>**Lone** (孤單) $\rightarrow$ **Lonesome** (寂寞的) |

---

## 💡 心智圖邏輯歸納

```text
基底詞性（被修飾的原詞性）
 ├── 名詞 (Noun)  ──► 側重「屬性、質地、材質、充滿」
 │   ├── -al, -ous, -ful, -y (充滿/相關)
 │   ├── -en (材質)
 │   └── -less, -ish (缺乏/像...一樣)
 │
 ├── 動詞 (Verb)  ──► 側重「動作傾向、能力、主被動」
 │   ├── -ive (主動傾向)
 │   ├── -able / -ible (被動能力: 可被...)
 │   └── -ing / -ed (外在令人... / 內在感到...)
 │
 └── 形容詞 (Adj) ──► 側重「程度微調」
     └── -ish (偏向.../微...)
```
